# worldtime table
A timezone comparison tool that lets you see multiple cities side by side, hour by hour. Drag the slider to explore times across the day. Auto-detects your local timezone, highlights business hours, and remembers your saved timezones across sessions
v1 — v1.html · Initial version
v2 — index.html · Added timezone persistence and DST support
v3 - index.html · Updated minor UI (color, border, and made the "X" button persistent) and made it into a Google Chrome Extension.
